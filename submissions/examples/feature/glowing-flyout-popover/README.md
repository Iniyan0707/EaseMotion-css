# Glowing Flyout Popover (Dark Mode Variant)

A lightweight, accessible, pure CSS implementation of a glowing flyout popover designed with dark-mode aesthetic tokens and smooth state transitions.

## Features
- **Zero JS Mechanics:** Built using the CSS `:checked` checkbox hack for state toggle.
- **EaseMotion Design Tokens:** Integrates standard easing curves and color tokens.
- **Ambient Glow Backdrop:** Subtle CSS multi-layer blur gradient background.
- **Fully Responsive:** Transforms into a bottom sheet drawer visual pattern on small mobile screens.
- **Accessibility:** Honors `prefers-reduced-motion` to strip transform animations for users who request it.

## Usage
1. Include `style.css` in your project or import the component styles.
2. Embed the structure defined in `demo.html`.
3. Override custom property tokens (`--em-accent-glow`, `--em-bg-popover`) to customize colors as needed.
