# Glowing Infinite Carousel (Neumorphism Variant)

A pure CSS infinite horizontal carousel featuring soft neumorphic extruded light/dark drop-shadows combined with ambient back-glow hover highlights.

## Features
- **Zero JavaScript Dependencies:** Continuous motion achieved strictly using CSS keyframe animations and duplicated element nodes.
- **Neumorphism Design Language:** Soft dual-shadow depth combined with rounded geometry and inset icon cutouts.
- **Hover Pause State:** Automatically pauses the track motion on hover (`animation-play-state: paused`).
- **Responsive Layout:** Dynamically adjusts card dimensions and motion timing across mobile, tablet, and desktop screens.
- **Accessibility Compliance:** Respects `prefers-reduced-motion` settings by stopping continuous animations and falling back to touch/mouse horizontal scrolling.
